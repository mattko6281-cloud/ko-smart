### 4. 누락된 신규 기능 (v0.2.1 ~ v0.2.2 Beta 1·2차 통합 업데이트분)

현행 사용설명서에는 최근 추가된 **스마트 그림 정리(`✨ 스마트 그림 정리`)** 관련 기능이 전혀 수록되어 있지 않습니다:
1. **메인 툴바 단일 진입 버튼 (`[✨ 스마트 그림 정리]`) 및 원클릭 복원 (`[↩ 원본 복원]`)**
2. **모달 내 3단계 UI 모드 전환 (`일반 모드 A` / `고급 옵션 B` / `상세 검수 C`)**
   - **일반 모드 A (기본)**: 원클릭 안전 정리 + `"축 길이도 함께 맞춤"` 토글(기본 ON) + 1줄 요약/정돈 칩 + 좌우/탭 반응형 전후 비교(`100% / 115% / 130%`)
   - **고급 옵션 모드 B**: 개별 정리 기능 체크박스 조합 후 `[⚡ 옵션 변경 일괄 적용]`
   - **상세 검수 모드 C**: 충돌 진단 리포트(`true-ink` / `bbox-only`), 유닛별 `pt` 이동 수치·Hold 사유, TikZ 코드 비교
3. **6대 자동 라벨 정리 유닛 (Unit 3-A ~ Unit 3-G)**
   - 함수식 라벨 정렬 (`y=f(x)` 등)
   - 숫자 눈금 정렬 (`Unit 3-B`)
   - 원점 `O` 4방향 안전 정렬 (`Unit 3-D`)
   - 점 이름 라벨(`A, B, P, Q` 등) 겹침 해소 (`Unit 3-E`)
   - 축 문자 및 소문자 수학 라벨(`x, y, a, b, k` 등) 겹침 해소 (`Unit 3-F / D-2`)
   - 직선 이름(`l, m, n, \ell`) 가시 끝점 기반 자연 배치 (`Unit 3-G / D-3`)
4. **다중 추상 함수식(Type 2) 및 다중 직선 이름(D3-2) 대응 선택 카드**
   - 기하학적으로 대응 후보가 복수인 경우 자동 강제 변경하지 않고 기본 **`[원본 배치]`(`Hold`)**로 보호하며, 사용자가 그림을 직접 보고 **`[원본 배치]` / `[추천 배치]` / `[반대 배치]`** 썸네일 카드를 클릭해 즉시 전환·적용하는 워크플로우

6. **덮어쓰기 보호 확인창**: 스마트 그림 정리 적용 후 조이스틱 등으로 추가 수동 편집을 한 상태에서 `[↩ 원본 복원]`을 누르면 수정 내역 손실을 막기 위해 확인 모달을 띄우는 안전장치

## Ⅱ. KO-SMART 신규 사용설명서 개편 초안 (`Part A` + `Part B`)

> [!TIP]
> **개편 구조 설계 방향**
> - 사용설명서 모달 상단에 **`[⚡ A. 빠른 시작 가이드 (1분 요약)]`** 탭과 **`[📖 B. 전체 상세 사용설명서]`** 탭(또는 상·하단 연속 스크롤 + 빠른 목차 앵커)을 배치하여, 처음 사용하는 팀원은 1분 만에 핵심 흐름을 익히고 숙련자는 세부 컨트롤러 사양을 바로 찾을 수 있도록 구성합니다.

### Part A. 빠른 시작 가이드 (Quick Start — 6단계 핵심 워크플로우)

#### Step 1. TikZ 코드 입력 (`Raw TikZ Code`)
- 좌측 에디터 창에 AI(`INF_KICE TikZ 프롬프트` 활용)로 생성한 TikZ 코드를 붙여넣거나, 상단의 **`[평가원 기본 축 로드]`** 버튼을 눌러 표준 좌표축 템플릿으로 시작합니다.
- 입력한 코드는 브라우저에 실시간 **자동 저장(`Auto-Save`)**되어 새로고침해도 유지됩니다.

#### Step 2. 실시간 그래프 미리보기 (`Live Preview`)
- 코드를 입력하면 우측 도화지에 즉시 고화질 그래프가 렌더링됩니다.
- 도화지를 마우스로 잡고 드래그하여 화면을 이동(**드래그 스크롤**)할 수 있으며, 상단 슬라이더(`🔍 100%~200%`)로 화면 표시 배율을 조절할 수 있습니다.

#### Step 3. 원클릭 스마트 그림 정리 (`[✨ 스마트 그림 정리]`)
- 라벨이 선이나 축에 겹쳐 있을 때, 좌측 코드창 상단의 보라색 **`[✨ 스마트 그림 정리]`** 버튼을 클릭합니다.
- 복잡한 설정 없이 **일반 모드(`A`)**가 열리며, **함수식·숫자 눈금·원점(`O`)·점 이름·축 문자·직선 이름(`l, m`)** 정돈과 **축 길이 맞춤(기본 ON)**이 한 번에 수행됩니다.

#### Step 4. 원본 / 추천 결과 비교 및 배치 선택
- 모달 중앙에서 **원본 그림**과 **추천 결과**를 나란히(좁은 화면에서는 탭 전환으로) 비교하고 `100% / 115% / 130%` 배율로 확대해 확인합니다.
- 추상 함수식(`y=f(x), y=g(x)`)이나 직선 이름(`l, m`)이 여러 개인 도형에서는 하단에 **`[원본 배치]` / `[추천 배치]` / `[반대 배치]`** 선택 카드가 나타납니다. 카드를 클릭하면 추가 로딩 없이 추천 그림이 즉시 바뀌므로 눈으로 보고 가장 알맞은 배치를 고를 수 있습니다.

#### Step 5. 결과 적용 및 안전한 1클릭 원본 복원 (`[↩ 원본 복원]`)
- 모달 하단의 **`[✨ 선택한 결과 적용]`**을 누르면 정돈된 코드가 에디터에 반영됩니다. (`[그대로 두기]` 또는 `ESC`를 누르면 원본 코드가 그대로 유지됩니다.)
- 적용 후에도 좌측 코드창 상단에 나타나는 주황색 **`[↩ 원본 복원]`** 버튼을 누르면 언제든 직전 원본 코드로 즉시 되돌릴 수 있습니다. (적용 후 조이스틱 등으로 추가 수정을 했다면 덮어쓰기 전에 안전 확인창이 먼저 표시됩니다.)

#### Step 6. 한글(HWP) 자동 복사 및 세트 저장 (`[📥저장 & 📋HWP 자동복사]`)

#### 2. 조이스틱 및 개별 노드·전체 스케일 조절 (하단 컨트롤 바)
- **개별 노드 다중 선택 (`노드 선택…`)**:
  - 드롭다운에서 이동하거나 크기를 바꿀 라벨(점, 수식, 눈금 등)을 **1개 또는 여러 개 동시 선택**합니다.
- **조이스틱 (`▲ ▼ ◀ ▶`) 및 키보드 방향키 정밀 제어**:
  - 마우스로 조이스틱 화살표를 클릭하거나 키보드 방향키를 눌러 선택된 노드를 이동합니다:
    - **기본 클릭 / 방향키(`↑↓←→`)**: `1pt` 이동
    - **`Shift` + 방향키**: `10pt` 크게 이동
    - **`Alt` (또는 `Ctrl`) + 방향키**: `0.1pt` 초정밀 이동
- **개별 노드 폰트 (`A＋` / `A－`)**: 선택된 노드들의 `scale` 값만 개별적으로 키우거나 줄입니다.
- **전체 스케일 제어 (우측 하단)**:
  - **`T 전체폰트 (- / +)`**: 도화지 내 모든 텍스트·수식의 전역 `scale`을 조절합니다.
  - **`≡ 선두께 (- / +)`**: 보조선(`1pt`)과 메인 곡선(`1.5pt`)의 **2:3 두께 비율을 그대로 유지**하면서 전체 선 두께를 비례 조절합니다.
  - **`↔ 가로너비 (- / +)` / `↕ 세로높이 (- / +)`**: `x=Ncm`, `y=Ncm` 배율을 독립 조절하여 그래프의 가로·세로 프로포션을 맞춥니다.

#### 3. 그래프 축 길이 수동 조정 및 점·Domain 관리자
- **수동 축 길이 조절 (`X축 가로` / `Y축 세로`)**:
  - 하단 패널에서 X축 좌·우 끝과 Y축 상·하 끝 좌표를 **`0.2` 단위**씩 직관적으로 미세 조절합니다.
- **점 & 그래프 제어 플로팅 패널**:
  - 상단 그립(점 6개 아이콘)을 드래그해 원하는 위치에 두고 사용할 수 있습니다.
  - **점 마커 숨김/표시**: 각 점 옆의 눈 아이콘(`👁`)이나 `[전체 켜기 / 전체 끄기]`를 눌러 코드를 삭제하지 않고 `%` 주석 처리 방식으로 안전하게 점 마커를 숨기거나 다시 표시합니다.
  - **그래프 길이 (`Domain`) 제어**: `domain=A:B`가 지정된 곡선·직선의 시작점(`A`)과 끝점(`B`)을 `±0.1` 단위로 늘리거나 줄입니다.

#### 4. 스마트 그림 정리 — 일반(A) / 고급(B) / 상세 검수(C) 3단계 모드
스마트 그림 정리 모달 우측 상단에서 작업 목적에 따라 3가지 모드를 전환할 수 있으며, 마지막으로 선택한 모드는 사용자별로 기억됩니다(최초 진입 시 **일반 모드 A**).
- **일반 모드 (`A`)**:
  - 버튼 하나로 6대 안전 라벨 정리 유닛(함수식, 숫자 눈금, 원점 `O`, 점 이름, 축 문자, 직선 이름)과 **축 길이 맞춤(`축 길이도 함께 맞춤`, 기본 ON)**을 실행합니다.
  - 축 길이를 원본 그대로 고정하고 라벨만 옮기고 싶다면 모달 상단의 **`[축 길이도 함께 맞춤]`** 체크를 해제하면 즉시 라벨만 정돈된 결과로 재계산됩니다.
- **고급 옵션 모드 (`B`)**:
  - 개별 기능(`숫자 눈금 정렬`, `점 이름 겹침 해소`, `축 문자 겹침 해소`, `직선 이름 정렬`, `4방향 축 자동 연장`, `Safe Shrink`, `그래프 끝점 미세 연장`)을 원하는 대로 체크·해제한 뒤 **`[⚡ 옵션 변경 일괄 적용]`** 버튼으로 한 번에 실행합니다.
- **상세 검수 모드 (`C`)**:
  - 각 라벨의 실제 잉크 충돌(`true-ink`) 및 바운딩박스(`bbox-only`) 진단 수치, 유닛별 이동량(`dx, dy pt`), 보류(`Hold`) 사유 코드, 원본 대 추천 TikZ 코드 비교를 상세히 확인합니다.

#### 5. 다중 추상 함수식(Type 2) 및 직선 이름(D-3) 배치 선택 가이드
- **왜 선택 카드가 나타나나요?**
  - 그래프에 식이 구체적으로 적히지 않은 추상 함수 라벨이 2개 이상(`y=f(x), y=g(x)`) 있거나, 비축 직선이 2개 이상이고 직선 이름(`l, m`)이 여백에 떠 있는 경우, 수학 문제의 의도에 따라 어느 라벨이 어느 선에 대응하는지 최종 확인이 필요합니다.
- **안전한 기본값 (`[원본 배치]` Hold)**:
  - KO-SMART는 추측으로 라벨 소속을 임의 변경하지 않고 항상 **`[원본 배치]`**를 기본 선택합니다.
- **3가지 후보 비교 (`[원본 배치]` / `[추천 배치]` / `[반대 배치]`)**:
  - 각 카드를 클릭하면 상단 비교 화면의 추천 그림이 즉시 전환됩니다. 함수식(3가지)과 직선 이름(3가지)이 함께 있는 도형에서도 총 `3×3=9`가지 조합을 지연 없이 비교하고 적용할 수 있습니다.

#### 6. 축 길이 맞춤(4방향 연장), Safe Shrink 및 Domain 미세 연장
- **축 길이도 함께 맞춤 (4방향 축 연장 — 일반 모드 A 기본 ON)**:
  - 정돈된 라벨이나 곡선 끝이 화살표 끝에 너무 가깝거나 축 밖으로 나가는 경우, 필요한 방향(`+x, -x, +y, -y`)으로만 축을 자연스럽게 연장하고 화살표 끝 축 문자(`x, y`)도 함께 이동시킵니다.
  - 이미 축 여백이 충분한 도형이나 축이 없는 순수 기하 도형에서는 축을 무리하게 늘리지 않고 원본 축을 그대로 보존합니다.
- **축 길이 안전하게 줄이기 (`Safe Shrink` — 고급 모드 B / 상세 모드 C에서 선택)**:
  - 축 꼬리가 그래프 내용에 비해 과도하게 길게 뻗어 있을 때, 그래프 끝점·점선·보조선·클리핑(`clip`)·음영(`fill`) 보호 잠금과 최소 비례 여백(`Proportional Stem Floor`)을 지키는 범위 안에서만 안전하게 축을 줄입니다.
- **그래프 끝점 미세 연장 (`Domain Extension` — 고급 모드 B / 상세 모드 C에서 선택)**:
  - 곡선 끝점이 축 화살표보다 살짝 짧아 어색할 때 안전 게이트 범위 내에서 `domain`을 미세 연장합니다.

#### 7. 사용 시 주의사항 및 지원되지 않는 유형 (안전 보류 Hold 안내)
- **미리보기 확인 필수**: `[✨ 선택한 결과 적용]`을 누르기 전 반드시 모달의 비교 화면에서 수식과 점의 위치가 문제 의도와 맞는지 확인하세요.
- **자동 변환을 보류(`Hold`)하고 원본을 지키는 유형**:
  - 다음과 같은 경우에는 그림 훼손을 막기 위해 엔진이 무리하게 위치를 바꾸지 않고 안전하게 **보류(`Hold`)**합니다. 이 경우 하단 **조이스틱(`▲▼◀▶`)**을 사용하면 `1pt` 단위로 손쉽게 미세 조정할 수 있습니다:
    1. 좌표축이 없는 순수 기하 도형(삼각형, 원, 다각형 단독 도형)에서의 축 기반 연산
    2. `\clip` 영역 경계나 `\fill` 음영 영역과 강하게 결합되어 이동 시 도형이 잘릴 위험이 있는 라벨
    3. 주변 모든 후보 방향에 곡선·보조선이 밀집해 있어 어디로 옮겨도 새로운 겹침이 발생하는 고밀도 영역
    4. 표준 TikZ `\node` / `plot` 형식이 아닌 특수 매크로(`foreach` 내부 동적 생성 노드 등)
